# Кейс-задача №5 — «Дневник путешествий»

Локальный сайт для хранения личных поездок и просмотра открытых рассказов других участников. Стек: Flask, SQLite, серверные HTML-шаблоны.

## Запуск

Требуется Python 3.10+.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000. Зарегистрируйте аккаунт, добавьте поездку и проверьте публичный просмотр в другом браузере/сеансе.

## Возможности по заданию

- Регистрация и вход с хешированием паролей.
- Создание аккаунтом собственных поездок и просмотр своих записей.
- Просмотр поездок, открытых другими участниками; автор может закрыть запись.
- Для каждой поездки: название, место (географическое описание текстом), даты, рассказ.
- Дополнительные детали: фото по внешней ссылке, стоимость, культурное наследие, места для посещения.
- Оценки удобства, безопасности, населённости и растительности по шкале 1–5.
- Поиск поездок по месту, названию и рассказу; удаление своей записи.

## Аналитическая часть (7+ пунктов)

1. Роли: гость, участник, автор поездки.
2. Сущности данных: аккаунт и поездка, связанные владельцем.
3. Основной сценарий: регистрация → описание путешествия → публикация/сохранение.
4. Доступность поездки задаётся автором как открытая или личная.
5. Географическое место записывается как текст, пригодный для поиска.
6. Даты позволяют упорядочить рассказ по периоду поездки.
7. Фото, культурные объекты и места посещения дополняют описание впечатлениями.
8. Стоимость и четыре субъективные оценки дают практический контекст для планирования.
9. Поиск по описанию помогает находить подходящие рассказы без отдельной карты.

## Ограничения

Геолокация принимается текстом, карты и GPS нет. Фото задаётся URL, файл не загружается и валидность/безопасность удалённого содержимого не проверяется. Стоимость сохраняется числом без валюты. Оценки являются субъективными. Прототип не включает CSRF-защиту, восстановление пароля и промышленную безопасность. Точный исходный текст методички не удалось получить из ссылки на разговор; покрытие основано на требованиях из запроса.
